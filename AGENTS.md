# Project agent contract

Treat active `REQUEST` plus imported documents as authoritative project inputs. The framework-owned work-item control governs scope, risk, verification, rollback, and hardware policy. Planning binds exact implementation scope, planner-selected registered verification lanes, and consequence-based risk. The initial execution profile is only a hint. Framework-managed work owns branch/worktree, candidate commit, verification, push, and PR publication. Preserve audit/evidence history and never bypass candidate-SHA, approval, or hardware controls.
